# 🎯 Number Guessing Game using Python

A simple Python command-line game where the player tries to guess a randomly generated number within a given range.

The program provides hints whether the guessed number is too high or too low until the correct number is guessed.

---

## 🚀 Features

* Random number generation
* User-defined range
* Hint system (Higher/Lower)
* Guess counter
* Beginner-friendly project

---

## 🛠 Technologies Used

* Python
* Random Module
