# 🎯 Number Guessing Game

A simple and fun **Python-based number guessing game** where the computer randomly selects a number, and the player tries to guess it in as few attempts as possible!

---

## 🧩 Features

- Accepts a user-defined upper limit for the random number range  
- Generates a random number between `0` and your chosen limit  
- Provides hints whether your guess is **too high** or **too low**  
- Displays the total number of attempts taken to guess correctly
